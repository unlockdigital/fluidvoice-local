## 2026-10-28 Windows branding delta

The maintained product was renamed from FluidVoice Hardened to **FluidVoice Local**, with repository slug [unlockdigital/fluidvoice-local](https://github.com/unlockdigital/fluidvoice-local). Historical commit subjects, upstream references, license text, copyright notices and `SOURCE-ORIGIN-SHA256SUMS` retain their original contents.

The Windows delta changes app assembly/output and product metadata, tray and accessible overlay text, insertion error text, `SecureProfile.ProductName`, installer policy/product and default destination, firewall display names/path, privacy-check executable/process/path references and the logic fixture's assembly load. Technical namespaces, manifest identity, mutex, startup registry value and hidden hotkey captions remain compatible as documented in [README](README.md#windows-rename-and-deployment). The overlay drawing geometry remains unchanged.

Beyond the import's three revised documents, the origin-ledger files changed by this rename are `src/FluidVoice.App/FluidVoice.App.csproj`, `src/FluidVoice.App/VoiceApplicationContext.cs`, `src/FluidVoice.App/RecordingOverlayForm.cs`, `src/FluidVoice.App/UnicodeTextInjector.cs`, `src/FluidVoice.Core/SecureProfile.cs`, `scripts/Install-FluidVoice.ps1`, `scripts/Set-FluidVoiceFirewall.ps1`, `scripts/Test-FluidVoicePrivacy.ps1` and `tests/logic/Program.cs`. The solution moves from ledger path `FluidVoice.Hardened.Windows.slnx` to `FluidVoice.Local.Windows.slnx` with its bytes unchanged. README, NOTICE and this provenance record also describe the current name and migration implications. Other retained origin-ledger files preserve their input bytes. The reviewed upstream icon reference and original license files remain unchanged.

The 2026-10-27 report of 299 matching publish files describes the pre-rename payload. The renamed assembly, metadata and strings require a new isolated publish and fresh binary/host validation.
